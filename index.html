02 · Featured Work

ECCV 2026 DOME‑HDR

Dual‑Output Multi‑Exposure HDR Reconstruction via SDR Fusion and Gain Map Inverse Tone Mapping

Jinho Kim, Jinwoo Kim, Seon Joo Kim

DOME‑HDR reconstructs both a standard‑dynamic‑range image and a full HDR image from three bracketed exposures in a single pass. A LoRA‑adapted diffusion model first synthesizes a balanced SDR image, guided by a dual cross‑attention module that pulls structural and color detail from the under‑ and over‑exposed frames while keeping the mid‑exposure frame as an anchor. This SDR result then drives an HDR Prior‑guided Gain Map network that predicts a spatially varying gain map, expanding the dynamic range in a way that stays consistent with the SDR output.

ECCV 2026 LIIFusion

LIIFusion: Coarse‑to‑fine Framework for Generative MEF via Implicit Neural Representation

Sangmin Han, Jinho Kim, Jinwoo Kim, Dongyoung Kim, Seon Joo Kim

Multi‑exposure fusion aims to combine differently exposed shots into one image with an extended dynamic range, but overexposed regions often need generative completion, and existing diffusion‑based methods are slow and lose fine structure. LIIFusion runs a low‑resolution generative stage that restores structure in blown‑out highlights through adaptive exposure correction, then a local implicit function upsamples the result at arbitrary resolution by directly querying the high‑resolution exposure sources — up to 3.5× faster than prior generative methods, with matching or better structural and perceptual quality.
